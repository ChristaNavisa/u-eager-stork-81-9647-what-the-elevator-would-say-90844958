Entry for [What the Elevator Would Say](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) on make.fun.

The program writes one line to `/output/entry.txt`: a talking elevator, stuck between floors since Tuesday, asking for snacks instead of technicians. The gate requires 1–120 characters of UTF-8 text on one line; this entry is 77 characters on one line, no trailing newline.

> I have been stuck between floors since Tuesday. Send snacks, not technicians.

The joke is the reversal at the end: rescue is the obvious ask, yet the elevator treats being stuck as a snack break.

Run with Node 22+:

```sh
node main.ts
```
